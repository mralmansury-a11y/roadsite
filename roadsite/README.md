# موقع إدارة خدمات الطريق الدولي

موقع رسمي مبني بـ Python Flask وSQLite، بواجهة عربية RTL متجاوبة وخفيفة، بدون أي إطار عمل أو مكتبة خارجية في الواجهة.

---

## 1. التشغيل

### المتطلبات
- Python 3.10 أو أحدث

### الخطوات
```bash
cd project
python -m venv .venv

# Windows
.venv\Scripts\activate
# Linux / macOS
source .venv/bin/activate

pip install -r requirements.txt
flask --app app run          # أو: python app.py
```
ثم افتح: `http://127.0.0.1:5000`

### متغيرات البيئة (موصى بها في الإنتاج)
| المتغير | الغرض | القيمة الافتراضية |
|---|---|---|
| `SECRET_KEY` | مفتاح تشفير الجلسات | `change-this-secret` (غير آمن) |
| `ADMIN_PASSWORD` | كلمة مرور المدير الأول عند إنشاء القاعدة لأول مرة | `admin123` |

> **قاعدة البيانات:** يُنشأ الملف `site.db` تلقائيًا عند أول تشغيل. إن كانت لديك قاعدة بيانات سابقة، انسخها إلى جذر المشروع بجوار `app.py`. لم تُضمَّن `site.db` في الحزمة حتى لا تستبدل بياناتك الحالية.

### إدارة حسابات المدراء
```bash
flask --app app admin list
flask --app app admin create USERNAME
flask --app app admin passwd admin      # غيّر كلمة المرور الافتراضية فورًا
flask --app app admin rename OLD NEW
flask --app app admin delete USERNAME
```

### لوحة الإدارة
- الرابط: `/admin/login` (ويوجد رابط "دخول الإدارة" في التذييل)
- المحتوى: الإحصائيات، ورسائل التواصل، وإدارة الأخبار والخدمات.

## 3. الملفات الجديدة

| الملف | الوصف |
|---|---|
| `templates/_macros.html` | ماكرو `icon()` للأيقونات، وماكرو `page_head()` لترويسة الصفحات الداخلية |
| `static/js/ui.js` | قائمة الجوال، وإغلاق التنبيهات، والتحقق من نموذج التواصل |
| `static/fonts/*.woff2` | خط Cairo مستضاف محليًا: مجموعتان فرعيتان (عربي ولاتيني) × وزنان |
| `static/img/icons.svg` | ملف أيقونات SVG موحد (sprite) يُخزَّن مؤقتًا في المتصفح |
| `static/img/logo-icon-*.png/.webp` | أيقونة الشعار (المعيّن فقط) بخلفية شفافة: 48 و96 و192 و512px |
| `static/img/logo-full-*.webp` | الشعار الكامل بالنص بخلفية شفافة: 240 و480px |
| `static/img/favicon.ico`, `apple-touch-icon.png` | أيقونات المتصفح والهاتف |
| `static/img/hero-*.webp` | خلفية القسم الرئيسي (640 و1288px) |
| `static/img/supervision-*.webp` | صورة قسم العناية والإشراف (640 و1288px) |
| `static/img/desert-road-*.webp` | صورة قسم الدعوة للتواصل (800 و1280px) |
| `static/img/entity-mark-*.webp`, `vision-2030-*.webp` | شعار الجهاز الوطني للتنمية وشعار رؤية ليبيا 2030 |
| `static/img/og-cover.jpg` | صورة المشاركة على الشبكات الاجتماعية (1200×630) |
| `static/site.webmanifest` | بيانات تطبيق الويب والأيقونات |

## 4. الملفات المعدَّلة

| الملف | سبب التعديل |
|---|---|
| جميع القوالب الثمانية + `base.html` | إعادة التصميم الكاملة المطلوبة. **بقيت كما هي:** أسماء المسارات، وأسماء الحقول، ومتغيرات Jinja، وحقل `csrf` المخفي في كل نموذج POST، ونماذج الحذف والقراءة والخروج كطلبات POST |
| `static/css/style.css` | استُبدل بالكامل بالتصميم الجديد، التزامًا بشرط "ملف CSS واحد" |

> القوالب نُقلت إلى `templates/` والأصول إلى `static/`، وهي البنية القياسية التي يتوقعها Flask.

## 5. التخصيص لاحقًا

### تغيير الألوان
جميع الألوان معرَّفة في أعلى `static/css/style.css`، في القسم **2) المتغيرات**:
```css
:root{
  --asphalt:#222327;  /* الفحمي: الترويسة والتذييل والأقسام الداكنة */
  --sand:#d8be9b;     /* الذهبي: الأزرار وخط الطريق المتقطع */
  --sand-2:#c7a87e;   /* الذهبي عند المرور (hover) */
  --bronze:#7a5c33;   /* الذهبي الداكن للنصوص على الخلفيات الفاتحة */
  --paper:#f6f5f2;    /* خلفية الصفحة */
}
```
ألوان الوضع الداكن معرَّفة في الكتلة التي تليها مباشرة: `@media (prefers-color-scheme:dark)`.

> عند تغيير `--bronze` حافظ على تباين لا يقل عن 4.5:1 مع الأبيض.

### تغيير الشعار
1. جهّز نسخة PNG شفافة من أيقونة المعيّن، ونسخة كاملة بالنص.
2. استبدل الملفات في `static/img/` بنفس الأسماء والمقاسات:
   - `logo-icon-96.webp`: الترويسة والتذييل.
   - `logo-icon-192.png` و`logo-icon-512.png`: ملف manifest.
   - `logo-full-480.webp`: صفحتا الدخول ومن نحن.
   - `favicon.ico` و`apple-touch-icon.png`: أيقونات المتصفح والهاتف.
3. حدّث صورة المشاركة `og-cover.jpg` (1200×630).

### تغيير بيانات التواصل
عدّل القاموس `SITE` في أعلى `app.py`، وتنعكس القيم تلقائيًا في الترويسة والتذييل وصفحة التواصل وبيانات SEO:
```python
SITE = {"name": "...", "en": "...", "phone": "...", "email": "...", "address": "..."}
```
> هذا تعديل بيانات وليس تعديل منطق. ملاحظة: القيمة الحالية لـ `en` هي "INTERNATIONAL ROAD SERVICES"، بينما الشعار يحمل "Toll Road Services Management"، فوحّدهما إن لزم.

ساعات العمل نص ثابت في `templates/contact.html`.

### تعديل النصوص الثابتة
| النص | الملف |
|---|---|
| القسم الرئيسي والنبذة ودعوة التواصل | `templates/index.html` |
| النبذة الرسمية والرؤية والرسالة والقيم | `templates/about.html` |

### أيقونات الخدمات
تُعيَّن بالترتيب من القائمة `svc_icons` في `index.html` و`services.html`، وتتكرر بعد العنصر الرابع. الأيقونات المتاحة موجودة في `static/img/icons.svg`، ويمكن إضافة أيقونة جديدة بعنصر `<symbol id="...">`.

## 6. ملاحظات تقنية

- **تصنيف رسائل التنبيه:** `app.py` لا يمرّر تصنيفًا للرسائل، لذلك يعامل القالب ما يبدأ بـ "تم" كرسالة نجاح، وما سواه كتنبيه خطأ. اتبع هذا النمط عند إضافة رسائل جديدة.
- **التحقق في نموذج التواصل:** يجري في المتصفح بشروط مطابقة للخادم، والتحقق في الخادم يبقى هو المرجع.
- **الإنتاج:**
  - لا تستخدم `debug=True`.
  - شغّل التطبيق عبر خادم مثل gunicorn أو waitress خلف nginx.
  - فعّل ضغط gzip أو brotli.
  - أضف ترويسة `Cache-Control` طويلة لمجلد `/static`.
- **نتائج Lighthouse للجوال** (خادم التطوير، بدون ضغط):
  | الصفحة | الأداء | الإتاحة | أفضل الممارسات | SEO |
  |---|---|---|---|---|
  | `/` | 96 | 100 | 100 | 100 |
  | `/contact` | 98 | 100 | 100 | 100 |
  | `/news` | 99 | 100 | 100 | 100 |
- **رخصة الخط:** Cairo مرخّص بـ SIL Open Font License، وتجد نص الرخصة في `static/fonts/OFL-Cairo.txt`.
